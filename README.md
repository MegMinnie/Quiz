   <p>Este projeto lúdico consiste em um quiz sobre bruxas, desenvolvido com HTML, CSS e JavaScript, responsivo em todos os formatos. Ao responder às perguntas, ele informa se você é uma bruxa, poderia ser uma bruxa ou não é uma bruxa. Vale lembrar que essas perguntas e resultados são fictícios, com o único objetivo de entretenimento. Ademais, foi implementado a propriedade scroll do CSS para rolar entre as perguntas.</p>
